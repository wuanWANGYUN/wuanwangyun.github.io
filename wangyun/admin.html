给文字与图片一个家

内容管理

用 Pages CMS 写文章、上传图片。保存后，网站会随 GitHub Pages 部署更新。

进入管理后台 ↗

将在新标签页打开 Pages CMS，用你的 GitHub 账号登录。

第一次使用

  1. 登录 GitHub。进入后台后，选择用 GitHub 登录。
  2. 授权这个网站仓库。如果提示安装 GitHub App，选择 Only select repositories，再选择 wuanwangyun.github.io。权限以 GitHub 授权页实际显示为准。
  3. 打开网站内容。选择账号 wuanWANGYUN、仓库 wuanwangyun.github.io 和分支 main。左侧会出现「文章管理」「相册管理」。

写一篇文章

  1. 打开「文章管理」，在「我的文章」中添加一项。
  2. 填写标题、日期和正文。封面和摘要可以留空；正文工具栏可以插入图片、链接、列表和引用。
  3. 检查编辑器内的图文排版，点击保存（Save），等待网站部署完成。

再次展开同一条目即可修改。删除该条目并保存，会从网站移除文章。

添加一张图片

  1. 打开「相册管理」，在「我的图片」中添加一项。
  2. 上传或选择图片，写一句图片说明。
  3. 点击保存。发布后，读者可以在相册中点击图片放大查看。

支持 JPG、PNG、WebP、GIF、AVIF。建议先压缩大图；只上传到媒体库的文件不会自动出现在相册。

保存之后

更新需要等待部署，通常不会立刻显示。可以查看部署进度 ↗，成功后刷新网站。

你的仓库是公开的，上传的文件和历史版本可能被访问。删除相册条目只会移除展示；若要删除媒体文件，请先确认其他文章没有引用它。

Pages CMS 的授权以整个所选仓库为范围，并非仅限本网站子目录。只有你授权的账号可以管理内容，普通读者看到这个入口也不能直接编辑。

使用说明依据 Pages CMS 官方文档。无需在此页面输入密码或访问令牌。
